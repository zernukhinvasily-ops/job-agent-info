Privacy policy

Job Agent is a private automation used by one person, its owner, for their own job search. Only the owner's own Google account is connected to it.

What it accesses

  • Gmail: reads messages carrying the owner's "Jobs" label (forwarded job alerts) and sends one summary email per day to the owner. It does not change, label or delete mail.
  • Google Sheets: reads and updates the owner's job tracker and its archive.
  • Google Drive: creates application documents in one folder of the owner and reads them back to check them.

How the data is used and stored

  • The data is used only to run the owner's job search: to identify vacancies, record them in the tracker and prepare documents.
  • Working data is stored on a server controlled by the owner and in the owner's own Google account.
  • Job descriptions and draft text are sent to a language-model API for scoring and drafting, with response storage turned off.
  • No data is sold, shared with third parties or used for advertising, and Google user data is not used to train models.

Google API Services User Data Policy

Job Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
